## Project
Educational machine-learning demonstration using a Random Forest classifier for neonatal high-risk profile prediction with SHAP and LIME-style local explanations. The dataset is synthetic and must not be used for clinical decisions.

## Run
```bash
pip install -r requirements.txt
python src/train_model.py
streamlit run app.py
```
